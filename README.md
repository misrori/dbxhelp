# dbxhelp: Databricks course supplements

Extra notebooks, slides and notes for Databricks courses. Each topic can be pulled into a Databricks workspace with **one line**, from a notebook running on **Serverless**.

🌐 **Site with copy-ready commands:** https://misrori.github.io/dbxhelp/

## Quick start (inside Databricks)

Open any Python notebook (Serverless), paste into a cell and run:

```python
import urllib.request as u; exec(u.urlopen("https://raw.githubusercontent.com/misrori/dbxhelp/main/dbxhelp.py").read().decode()); dbxhelp("genie/metric-views")
```

`dbxhelp()` without arguments lists all topics. Notebooks land in `/Workspace/Users/<you>/dbxhelp/<module>/<topic>/`.

## From a local terminal (git + Databricks CLI)

```bash
D="${TMPDIR:-/tmp}/dbxhelp"; (git -C "$D" pull -q 2>/dev/null || git clone -q --depth 1 https://github.com/misrori/dbxhelp.git "$D") && \
databricks workspace import-dir "$D/modules/genie-conversational-agents/metric-views" "/Workspace/Users/<you@company.com>/dbxhelp/Genie - Conversational Agents/Metric Views" --overwrite
```

Or use a **Git folder** in the UI: *Workspace → Create → Git folder → `https://github.com/misrori/dbxhelp`*.

## Synthetic data for demos

Demos never create schemas. Fill in **one variable**, then load the data from GitHub into Delta tables with one line:

```python
WORK_SCHEMA = "FILL_IN"   # "<catalog>.<schema>" you can write to, e.g. dbacademy.<your labuser schema>

import urllib.request as u; exec(u.urlopen("https://raw.githubusercontent.com/misrori/dbxhelp/main/dbxdata.py").read().decode())
S = load_dataset("retail", WORK_SCHEMA)   # creates the tables, runs USE CATALOG/SCHEMA, returns `catalog`.`schema`
```

| Dataset | Tables | Generated by |
|---|---|---|
| [`retail`](data/retail/) | `dim_customer` (500), `dim_product` (40), `fact_orders` (60,000), with comments and PK/FK `RELY` | `python3 tools/generate_data.py` |

If the notebook can't reach GitHub, clone the repo as a Git folder and pass `source="/Workspace/<path-to-git-folder>/data"`.

## Repository layout

```
catalog.json                     # registry of modules/topics (drives loader + site)
dbxhelp.py                       # loader executed inside Databricks (imports notebooks)
dbxdata.py                       # loads data/<dataset>/ into Delta tables in a schema you choose
data/<dataset>/                  # synthetic CSVs + dataset.json (columns, types, comments, keys)
index.html                       # GitHub Pages landing page (generated)
modules/<module>/<topic>/
    01_lecture_*.sql|py          # Databricks notebook source (%md-sandbox styled)
    02_demo_*.py                 # runnable demo (Serverless)
    <topic>.md                   # notes, the single source for the HTML viewer (and for generated recap notebooks)
    <topic>.quiz.json            # optional knowledge check: rendered into the .md, the HTML and the notebook
    <topic>.html                 # Document ⇄ Presentation viewer (generated)
tools/build.py                   # regenerates index.html and <topic>.html
tools/templates/                 # HTML templates
```

## Adding a new topic

1. Create `modules/<module>/<topic>/` with a `<topic>.md` (and optionally `<topic>.quiz.json`). For recap-style topics, list a notebook with `"from_doc": true` in `catalog.json` and it is generated from the markdown. Otherwise add hand-written notebooks (files must start with `# Databricks notebook source` or `-- Databricks notebook source`) and a `<topic>.md`.
2. Register it in `catalog.json`.
3. In the markdown, every `## ` heading becomes a new slide in presentation mode (and a notebook cell).
4. Demos that need data: start with the `WORK_SCHEMA = "FILL_IN"` cell plus `load_dataset(...)`. Add new datasets to `tools/generate_data.py`.
5. Run `python3 tools/build.py`, then commit and push. GitHub Pages serves the repo root (`main` branch, `/`).
