dbxhelp

Supplementary notebooks, slides and notes for Databricks courses. Pull any topic into your workspace with one line, straight from a notebook running on Serverless.

How to load a topic into Databricks

1Open any notebook
In the lab workspace: New → Notebook, keep Serverless selected, language Python.
2Paste the command
Click Copy next to a topic below, paste it into a cell and press Shift+Enter.
3Open the link
The notebooks land in /Workspace/Users/<you>/dbxhelp/…. Click the printed link to open them.
Other ways to load

Works on Serverless with nothing to install: it uses the pre-installed databricks-sdk and imports the notebooks of one topic. List everything that's available:

Optional arguments: target="/Workspace/Shared/dbxhelp", overwrite=False, include_docs=False, branch="dev".

On your laptop, with the Databricks CLI authenticated to the lab workspace (databricks auth login --host https://<workspace-url>). The command clones (or updates) the repo and uploads one topic folder.

Each topic below also has its own terminal command.

  1. In the workspace: Workspace → your home folder → Create → Git folder.
  2. Git repository URL: https://github.com/misrori/dbxhelp (provider: GitHub, public repo, no token needed).
  3. Optional: Advanced → Sparse checkout mode with a cone pattern like modules/genie-conversational-agents to pull just one module.
  4. Click Create Git folder. Later you can use ⋮ → Git… → Pull to get updates.

Topics

Tip: dbxhelp("de") or dbxhelp("ade") imports every topic of a module at once, e.g. all four recaps of a learning path.
